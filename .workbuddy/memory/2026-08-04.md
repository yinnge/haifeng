# 2026-08-04 工作日志

## 排查：NoClassDefFoundError - Lombok Builder 内部类找不到

**现象**：admin 端 8081 报 `NoClassDefFoundError: com/haifeng/admin/vo/university/UniversityGuideListVO$UniversityGuideListVOBuilder`，
由 Jackson `getDeclaredMethods0()` → `ClassUtil.getClassMethods()` 触发，序列化分页 records 列表时炸。

**根因（非代码 bug）**：应用运行期间执行了 `mvn clean` / IDE Rebuild。
- 报错日志 PID=47012，当前 8081 监听进程仍是 47012 → 同一 JVM 未重启
- `haifeng-admin/target/` 目录整体在 22:16:05 被删除重建，class 文件 22:16:39 才写回
- JVM 懒加载：外层 `UniversityGuideListVO` 早已加载进方法区（不受磁盘删除影响），
  但内部 `...Builder` 类从未加载过，Jackson 首次内省需解析 `builder()` 返回类型 →
  去磁盘找 class → 正处于 clean 后、编译完成前的窗口 → ClassNotFoundException → NoClassDefFoundError
- 源码本身正常：`@Data @Builder @NoArgsConstructor @AllArgsConstructor` 齐全，Lombok 工作正常

**解法**：重启应用（PID 47012）。磁盘产物已完整，重启即恢复。

**预防（项目约定）**：
- 本项目 pom **未引入 spring-boot-devtools**，没有热重载能力
- 严禁在应用运行时执行 `mvn clean` / IDEA "Rebuild Project"；需要重编译先停服务
- 同类症状识别特征：报错类名带 `$XxxBuilder` / `$1` 等内部类后缀 + Jackson 反射栈 = 编译产物与运行 JVM 不一致，先看 target 时间戳和 PID，不要去改代码
