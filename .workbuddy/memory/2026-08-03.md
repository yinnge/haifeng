## 前端续：统招入口「看不到按钮」根因修复 + 特殊通道页置顶入口
用户反馈在页面上看不到统招按钮。排查出**两个独立原因**：

**原因1（页面走错）**：导航「志愿填报」下拉有两个子项——「高考报志愿」→`/gaokao`(gaokao/index.vue)、「特殊通道」→`/special`(special/index.vue)。上一轮按钮加在 `/gaokao`，用户打开的是 `/special`。两者是完全不同的页面组件。
- 导航配置位置：`apps/user/src/config/navigation.ts`（AppHeader.vue 从这里读 navItems）
- 注意：navigation.ts 里「直通院校」子项也指向 `/gaokao`，与「高考报志愿」重复，疑似待补路由。

**原因2（真实缺陷，已修）**：`gaokao/index.vue` 的统招卡片是从后端 `getChannelList()` 结果里 filter `channelCode==='NORMAL'` 得到的。而 `V14__t_special_channel__tables.sql` **只建表、无任何 INSERT 初始化数据**，`t_special_channel` 全靠后台运营录入。运营没录 NORMAL 记录 → 统招卡片直接不渲染 → 入口消失。
- 修复：统招卡片改为**硬编码固定展示**，不再依赖后端数据；`channelCodes` 数组移除 'NORMAL'（只留其余5个通道）；`channelIcon`/`channelDesc` 删除已成死数据的 NORMAL 条目；`goChannel(item)` 简化为纯跳通道大学列表，统招逻辑抽出为独立 `goNormal()`。
- 空状态文案改为「暂无其他报考通道数据」并移出 grid（原 col-span-full 会破坏布局）。

**新增**：`views/special/index.vue` 顶部置顶统招入口横幅（用户要求：先按钮、后特殊通道分页）。
- 位置：`<main>` 内第一个块，在原「引导区」之前，原有 Tab/搜索/卡片/分页完全不动
- 复用同一套状态机：未建档→「填写高考档案 →」；已建档→「已建档」徽章+「进入报志愿 →」+「修改档案」
- **坑点**：`/special` 路由 meta 无 `requiresAuth`（公开页），直接调 `getArchive()` 未登录会触发 401。故先用 `useUserStore().isLoggedIn()` 短路判断，未登录直接按未建档处理。
- store 用法：`import { useUserStore } from '@/store/modules/user'`（目录是 `store` 不是 `stores`），`isLoggedIn` 是**方法**需加括号调用。

验证：vue-tsc --noEmit 0 错误。
